Данные можно править в приложении: вкладка «Редактор».
Папки по-прежнему можно копировать вручную.

Персонаж: name, owned, rarity, class, element, weaponType, stats.primary/secondary, 4 skills.
Навык 3 (комбо): comboFrom — от чего срабатывает; tags — что делает.
owned: true — персонаж в наличии, команды собираются только из них.
Ранг: 3, 4, 5, 6.
Класс: Страж, Заклинатель, Штурмовик, Авангард, Защитник, Поддержка.
Стихия: Физика, Тепло, Природа, Электро, Крио, Эфир.
Тип оружия: Меч, Модуль искусств, Двуручный меч, Древковое оружие, Пушка.
Показатели: strength, agility, intellect, will.
Оружие: name, rarity, type, tags.

Общий список тегов: data/tags.txt
Одна строка — один тег. Используется и у оружия, и у навыков персонажей.
После правки файла нажмите «Обновить» в приложении.
Физическое состояние считается общим для Подбрасывание, Опрокидывание, Разгром, Прорыв.
Поражение искусствами считается общим для Поражение теплом, Поражение электричеством, Поражение природой, Криогенное поражение.

Картинки: положите portrait.png / portrait.jpg или icon.png / icon.jpg в папку записи.
Если файла нет, в каталоге показывается знак вопроса.
