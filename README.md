# Endfield Suggester

Десктопное приложение для **Arknights: Endfield**: каталог оперативников и подбор отряда из тех, кто реально есть на аккаунте.

Это не тир-лист из интернета. Калькулятор смотрит на навыки в вашей базе — кто вешает поражение, кто ждёт реакцию, кому нужен последний удар — и предлагает пачку, в которой эти замки закрываются. Оружие пока почти не влияет на выбор персонажей.

Windows, Tauri 2 + React. Интерфейс на русском.

## Что умеет

- **Каталог.** Каждый оперативник — папка с `info.json` и портретом. Базу можно править в приложении или в проводнике.
- **Наличие.** Галочка «есть» (`owned`). Команды собираются **только** из отмеченных.
- **Команды.** Ставите одного или нескольких в слоты — программа добирает остальных, показывает архетип, почему пачка сложилась, и черновую ротацию.
- **Редактор.** Имена навыков, стихии ударов, теги, условия комбо и усиленных веток. Кнопка «Разобрать описание» предлагает теги по тексту навыка.
- **Эталоны.** Для известных гайдовых пачек (Лэватейн, Чжуан Фанъи, Ми Фу, Ивонна и другие) подставляется готовая ротация, а не общий шаблон.

## Как пользоваться

1. Запустите приложение (из исходников или из релиза).
2. Во вкладке **Редактор** отметьте, кого вы вытащили. Портрет — файл `portrait.png` в папке оперативника.
3. Откройте **Команды**, перетащите керри в слот 1 (или любого, от кого хотите собрать пачку).
4. Смотрите предложения: можно взять весь состав, выкинуть кого-то из добора, закрепить слот, исключить персонажа из поиска.
5. Слот 1 важен для **Си**: если там тепловой керри, она вешает тепло; иначе — крио.

Команды не предлагаются, пока в наличии никого нет.

## Как считается пачка

Коротко: программа ищет состав из четырёх, где выбранным персонажам есть чем закрыть комбо и усиленные ветки, плюс роли (керри, батарея ОН, поддержка) и стихийное ядро.

Архетипы, которые она различает:

| Ядро | Идея |
| --- | --- |
| Физика | Уязвимость (подброс / опрокид) → разгром или прорыв |
| Тепло | Поражение теплом / горение, часто вокруг Лэватейн |
| Электро | Поражение электричеством → электризация |
| Крио | Крио-поражение и застывание (Ивонна + Тантан + Гилберта) |
| Природа | Поражение природой / коррозия |
| Смешанный | Нет явного перевеса |

Выводы только из карточек в `data/`. Если у персонажа в файле нет тега — калькулятор этого не «догадается» из вики.

Оружие в скоринге сейчас слабое: тип и рекомендованные id дают немного очков, но не выбирают керри.

## Теги, комбо и «ждёт»

У каждого оперативника четыре навыка: базовая атака, боевой, комбо, ульта.

| Поле | Смысл |
| --- | --- |
| **tags** | Что навык **делает** или вешает. «Поражение теплом», «Застывание», «Подбрасывание». |
| **comboFrom** | От чего **вспыхивает комбо** (навык 3). Галочки в редакторе, не теги. |
| **needs** | Чего не хватает в пачке, чтобы открылась **усиленная ветка** (часто боевой или ульта). |
| **damage** | Стихии ударов. Канон персонажа — поле `element` на карточке; удары навыка могут отличаться. |

`comboFrom` и `needs` по умолчанию требуют **все** условия сразу. `comboFromMatch` / `needsMatch`: `"any"` — достаточно одного.

Примеры:

- Ивонна боевым **накладывает** застывание (`tags`), но **ждёт** крио- или природное поражение (`needs`, `any`).
- Гилберта комбо **ждёт** реакцию искусств (`comboFrom`), а тегом ставит подбрасывание.
- Алеш боевым **съедает** крио-поражение и ставит застывание: в `needs` крио, в `tags` застывание, не наоборот.

В редакторе это же расписано в свёрнутой **шпаргалке**. Список тегов — `data/tags.txt` (кнопка «Открыть tags.txt»).

Каноническая стихия на табличке персонажа не меняется, даже если в навыке другой удар.

## База данных

Рядом с исходниками — папка `data/`. В установленном приложении она копируется **без перезаписи** уже существующих файлов: ваши правки не затираются обновлением.

```
data/
  operators/<id>/info.json
  operators/<id>/portrait.png   # или .jpg; без файла будет заглушка
  weapons/<id>/info.json
  tags.txt
  _schema/                      # JSON Schema полей
  README.txt                    # краткая шпаргалка по полям
```

Идентификатор записи — имя папки (`levateyn`, `zhilberta`, `kamil`).

Минимум в `info.json`:

```json
{
  "name": "Ивонна",
  "owned": true,
  "rarity": 6,
  "class": "Штурмовик",
  "element": "Крио",
  "weaponType": "Пушка",
  "stats": { "primary": "intellect", "secondary": "agility" },
  "skills": [ { "name": "…", "tags": [], "damage": [{ "element": "Крио" }] } ]
}
```

Четыре слота навыков всегда. Пустые тоже хранятся.

Классы: Страж, Заклинатель, Штурмовик, Авангард, Защитник, Поддержка.

Стихии: Физика, Тепло, Природа, Электро, Крио, Эфир.

Оружие: Меч, Модуль искусств, Двуручный меч, Древковое оружие, Пушка.

После правок файлов вручную нажмите **Обновить** в приложении.

## Где лежат данные у собранного exe

1. Если рядом с `.exe` есть `data/operators/` — это **портативный** режим. Новые файлы из бандла дописываются, старые не трогаются.
2. Иначе база сеется в AppData (`%APPDATA%\com.endfield.suggester\data` или аналог Tauri) — тоже только недостающие файлы.

В режиме разработки всегда используется `data/` в корне репозитория.

## Сборка и запуск

Нужны Node.js, Rust (`rustup`) и Visual Studio Build Tools с workload **Desktop development with C++**.

```bat
npm install
dev.bat
```

`dev.bat` поднимает MSVC (`vcvars64`) и запускает `npm run tauri dev`.

| Команда | Что делает |
| --- | --- |
| `npm run tauri dev` | Разработка (нужен MSVC в PATH, либо `dev.bat`) |
| `npm run gold` | Проверка: эталонные пачки должны быть в топ-5 подсказок |
| `npm run release` | `tauri build` — установщик NSIS, база кладётся в ресурсы |

Релизный артефакт — Windows NSIS. Чтобы не потерять базу, не копируйте поверх своей `data/` вручную: установщик и портативный запуск дописывают только отсутствующие файлы.

## Ограничения

- Скоринг — эвристика под текущий ростер, не симулятор боя и не парсер ротаций с секундами.
- Стойки вроде INT/WILL у Серебристого потока в файле одна карточка: считается то, что записано в тегах.
- Оружие и сеты почти не участвуют в выборе команды.
- Эталонные ротации заданы вручную в `src/gold.ts`; для остальных пачек показывается общий порядок (повесить поражение → стеки → закрыть).
